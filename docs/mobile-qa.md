# Mobile QA checklist

Manual checks on a real phone before a release. The automated suites do not
cover these.

- Safe-area padding on notched phones (the home indicator does not cover Leave or other buttons)
- Share sheet and copy room code from the lobby
- Two tokens on one cell fan out (barrier and safe-cell stacks are tappable)
- Leaving during play returns home and forfeits the seat
- Create game submits with Enter from the name field
- Away-player banner shows when the current turn's seat is disconnected
- Home-screen install tip appears on phones and can be dismissed
- Haptics (where supported) on roll, capture and win
