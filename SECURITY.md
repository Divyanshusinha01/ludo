# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately
through GitHub's
[private vulnerability reporting](https://github.com/Divyanshusinha01/ludo/security/advisories/new).

Include the affected URL or file, steps to reproduce and the impact you expect.
You should get a reply within 7 days. Fixed issues are credited in the advisory
unless you prefer otherwise.

## Scope

In scope: this repository and the live demo at
[ludo-three-steel.vercel.app](https://ludo-three-steel.vercel.app), for example
cheating past server authority, reading another player's session, account
takeover, or injection.

Out of scope: denial-of-service and load testing against the live demo,
social engineering, and findings in third-party services (Vercel, Convex) that
are not caused by this code.

## Supported versions

Only the latest commit on `main` is supported.
