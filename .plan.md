# Act 3 — Multiplayer Product Depth (tracker)

Rule: a task is checked off only after every step of the verification protocol
below passes. On any failure the task stays unchecked and the failure is noted
under it.

## Tasks

- [x] **Task 1 — Signup/auth + persistent profiles**
  - Schema: `accounts`, `profiles`, `authSessions`, `authAttempts`; `players.accountId?`
  - Convex: `convex/auth.ts` (secret-gated signUp/logIn/changePassword/logOut/refreshSession), `convex/profiles.ts`, `convex/lib/auth.ts`, `convex/lib/rateLimit.ts`, `convex/auth.config.ts`
  - Next Route Handlers: `/api/auth/{signup,login,logout,password,token}` (IP from platform headers, shared secret, same-origin check)
  - httpOnly `ludo_session` cookie (30-day sliding) + short-lived RS256 JWT for Convex via `ConvexProviderWithAuth`
  - Remembered device, name/username prefill, seat linking (`players.accountId`)
  - Auth UI (`AuthPanel`) + profile page (`/profile`)
  - Tests: auth, rate limits, secret scans, password change, route handlers, IP helper, UI
- [x] **Task 2 — Matchmaking queue** (duel, ffa4, team2v2; idempotent join/leave; OCC-safe matcher; ranked rooms with accountId seat reclaim)
  - `convex/lib/roomFactory.ts`: room helpers moved out of `rooms.ts` + `createStartedRoom` (used by `createVsComputer` and the matcher)
  - Schema: `matchQueue` (one ticket per account); `rooms.ranked?`, `rooms.queue?`
  - `convex/matchmaking.ts`: `joinQueue`, `leaveQueue`, `queuePing`, `queueStatus`, internal `matchmake` (scheduled per join) + `sweep` (10s cron); pure grouping/seating in `convex/lib/matchmaking.ts`, DB helpers in `convex/lib/matchQueue.ts`
  - Ranked rooms: no rematch/kick/addBot; account owner reclaims its seat from any tab without host approval; strangers rejected
  - `cleanup.tick` drops stale waiting tickets and matched tickets whose game is over
  - UI: `MatchmakingPanel` in the Play Online menu; `RoomClient` auto-reclaims ranked seats; `GameScreen` hides rematch for ranked games
- [x] **Task 3 — Elo/rating** (pure `lib/rating.ts`, rating-aware window, settlement on `playing -> finished`, idempotent)
  - `convex/lib/rating.ts`: Elo (K 40 for first 30 rated games, then 24; floor 100), pairwise FFA scaled by 1/(n-1), 2v2 by team averages; acceptance window ±100 widening 50 per 10s (cap 500)
  - `formGroups`: oldest ticket anchors, members must be mutually inside each other's window; an unmatched anchor does not block younger tickets; re-joining refreshes the ticket's rating
  - `convex/lib/settlement.ts`: `settleRankedRoom`, called from `commitEvents` on `playing -> finished` in the same transaction; idempotent via `rooms.ratingSettledAt` (new optional field)
  - Profiles updated on settlement: `rating`, `peakRating`, `ratedGames`, `gamesPlayed`, `wins`, `lastActiveAt`
- [x] **Task 4 — Persisted match history and rating changes** (`matches`, `matchParticipants`, `history.*`, leaderboard, UI)
  - Schema: `matches` (`by_room` idempotency key, `by_finishedAt`), `matchParticipants` (`by_account_finishedAt`, `by_match`); self-contained snapshots that cleanup never deletes
  - `settleRankedRoom` writes the match + one participant row per account in the same transaction (rated games and voided/abandoned ones, the latter as `rated: false`, delta 0)
  - `convex/history.ts`: `listMine` (paginated, newest first, empty for anonymous), `getMatch`, `getRoomResult` (post-game banner), `leaderboard` (top N by rating, skips accounts with no rated games, limit clamped to 1–50)
  - UI: `MatchHistory` + `Leaderboard` on `/profile` (leaderboard also when signed out), `RatingResultBanner` in the finished ranked `GameScreen`
- [x] **Task 5 — Spectator mode** (`spectate.*`, read-only `GameScreen`, live list, reaping)
  - Schema: `spectators` (`by_room`, `by_room_spectator`, `by_lastSeenAt`); never seated, `spectatorId` never returned
  - `convex/spectate.ts`: `listLive` (ranked `playing` games only, names/ratings/watcher counts), `getSpectatorRoom` (the public room bundle built with no session, plus watcher count; null for vs-computer), `joinSpectate` / `spectatorPing` / `leaveSpectate` (idempotent, 50 live watchers per room); helpers in `convex/lib/spectate.ts`
  - Watching never touches the room, players or event log; `deleteRoomCascade` removes watcher rows; `cleanup.tick` reaps watchers silent for 45s
  - UI: `/spectate/[code]` renders `GameScreen` with `spectate` (badge + count, no controls, no seat heartbeats/metrics, "Stop watching"); `LiveGames` ("Watch live" + watch by code) in the Play Online menu

otherwise hand-update `convex/_generated/api.d.ts`.
